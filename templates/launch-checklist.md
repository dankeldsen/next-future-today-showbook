# Launch Checklist Template - Next Future Today

Run per episode, from recording done to two weeks post-launch. The episode isn't finished when it's edited - it's finished when the guest has promoted it and the notes are live.

---

# Launch: Ep. NNN - [Guest Name] - [Launch date]

## Post-production

- [ ] Edit video (cold open in first 60 seconds - no dead air, no long intros)
- [ ] Edit audio master
- [ ] Chapters/timestamps marked
- [ ] Title finalized (searchable + specific - see INDEX.md for house style)
- [ ] Episode description written (guest name, thesis, 3 key resources)

## Publish

- [ ] Audio live on host platform -> distributes to Apple, Spotify, etc.
- [ ] Video live (show site + YouTube if used)
- [ ] Episode-notes file created in `episodes/` from template, INDEX.md updated, links added
- [ ] Show-site episode page live

## Guest kit (within 24 hours of launch)

- [ ] Best-moment clip (60-90s) cut and sent
- [ ] 3 quote cards sent
- [ ] All links + pre-written social copy sent
- [ ] Personal thank-you note sent

## Promotion (launch day -> 2 weeks)

- [ ] Launch-day post: thesis + clip, not just "new episode"
- [ ] Guest tagged on the platform(s) they actually use
- [ ] Guest's organization tagged where appropriate
- [ ] LinkedIn newsletter mention (biweekly cadence)
- [ ] 1-week follow-up post: the best quote as a pull-card
- [ ] 2-week tie-in: connect episode thesis to the next episode's guest/topic

## Measure (2 weeks out)

- [ ] Listens/downloads vs. episode average
- [ ] Guest-driven engagement (their posts' performance)
- [ ] Inbound: DMs, follows, guest referrals - log them; referral guests close at a much higher rate
- [ ] Note what to repeat / kill in the format
